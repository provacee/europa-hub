# Europa Hub

## Visió
Europa Hub és la plataforma interna del Club Esportiu Europa.
Centralitza comunicació, fotografia, vídeo, scouting, oficina, socis i històric.

## Integracions inicials
- Mega
- SOGo
- Veo
- FCF
- Google Drive
- Canva

## MVP (v0.1)
- Autenticació
- Dashboard
- Centre de Peticions
